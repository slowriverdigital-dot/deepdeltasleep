2. TikTok API Integration

Our application integrates with TikTok's developer platform using the following products and scopes:

  • Login Kit — Used to authenticate TikTok user accounts and obtain authorization to post on behalf of authorized users.

  • user.info.profile — Used to retrieve profile details necessary for creator eligibility verification.
